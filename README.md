# REFAD – رِفاد | Smart Nursing Handover & Continuity Platform
> **معلومات متصلة، ورعاية مستمرة**

منصة ذكية متخصصة في تسهيل تسليم واستلام المناوبات التمريضية بين الكوادر الطبية بالاعتماد على الذكاء الاصطناعي وهيكل SBAR السريري المعياري، المصمم وفق معايير سلامة المرضى الدولية (JCI).

## 🚀 سيناريو العرض التجريبي التفاعلي (Demonstration Scenario)
- **المريض 101**: فهد العتيبي (58 سنة) – وحدة العناية القلبية (CCU)، غرفة 204.
  - تشخيص: بعد قسطرة علاجية وزراعة دعامة شريانية (Post-PCI STEMI).
  - علامات حيوية وأدوية مسجلة.
  - **فحص تروبونين مكرر معلق** (سحب الساعة 12:30 وقيد المعالجة بالمختبر).
  - **مهمة غير مكتملة**: فحص موضع وخز القسطرة الفخذية وتقييم النبض الساعة 16:00.
- **تدفق التجربة**:
  1. تقوم **الممرضة سارة** (المسلمة) بتوليد تقرير SBAR الذكي.
  2. يطلق **مكتشف النواقص (Missing Info Detector)** تنبيهين باللون الأصفر لوجود تحليل معلق ومهمة مستحقة في المناوبة القادمة.
  3. تراجع سارة التقرير، وتعتمد الترجمة السريرية الثنائية، ثم توقع وترسل التقرير.
  4. استلمت **الممرضة نورة** (المستلمة) إشعاراً فورياً، راجعت التقرير، وطلبت استيضاحاً أو أكدت استلام مسؤولية الرعاية.
  5. تم ترحيل المهام غير المكتملة تلقائياً لقائمة مهام المناوبة المسائية مع توثيق ذلك في سجل التدقيق غير القابل للتعديل.
  6. يتابع **مشرف التمريض** المؤشرات والرسوم البيانية التفاعلية عبر لوحة التحليلات المباشرة.

## 🛠️ كيفية التشغيل (How to Run)

### 1. تشغيل تلقائي بنقرة واحدة (Windows):
قم بتشغيل الملف:
```cmd
start.bat
```

### 2. أو تشغيل يدوي:
**تشغيل واجهة البرمجة الخلفية (FastAPI):**
```powershell
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

**تشغيل الواجهة الأمامية (Vite + React):**
```powershell
cd frontend
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
واجهة الـ API التفاعلية (Swagger UI): `http://127.0.0.1:8000/docs`
